# Stop and pivot ledger

| Hypothesis | Probe | Stop/pivot trigger | Response |
|---|---|---|---|
| Custom grammar beats native calls | paired protocol corpus | no material correctness/latency benefit, or lower coverage | native remains default; grammar stays experimental or is removed |
| Replay improves recovery affordably | reopen and rebuild benchmarks | replay cost requires early snapshots or causes operational complexity | compare simpler transactional state before expanding |
| Session/action kernel supports coding | no-op, edit, failure, cancellation scenarios | task/role state is required in kernel packages | revisit ownership before adding server/UI |
| Delegated runtime cannot satisfy trust boundary | observe pre-side-effect mediation | equivalent mediation/evidence with materially lower cost | evaluate it as a kernel runner |
| General policy abstraction is warranted | implement second policy | no genuinely shared semantics | retain concrete Go policy |
| WebSocket is the right live transport | reconnect/backpressure comparison | SSE+POST is simpler with equal correctness | choose SSE+POST |
